# Course context

This repository is a curated reconstruction of undergraduate C/C++ programming coursework completed in 2021.

The original archive contained basic programming exercises, debugging labs, CCF CSP practice, compiled binaries, Visual Studio project artifacts, PDFs, Word reports, and unrelated course materials. The public repository intentionally keeps only code and documentation that are appropriate for a software portfolio.

## CCF CSP course-design result

The original course-design report records 20 CCF CSP practice tasks with a total score of **1970/2000**:

- 19 tasks: 100/100
- CCF CSP 202112-2: 70/100

The archived `202112-1.cpp` and `202112-2.cpp` files were accidentally identical, and their shared content corresponds to the report’s 202112-2 approach. The correct 202112-1 solution and the historical 202112-2 implementation in this repository were therefore reconstructed from code printed in the original report. An additional optimized 202112-2 implementation demonstrates how the performance bottleneck can be removed.

## Public-repository policy

The following material from the original archive is deliberately excluded:

- compiled binaries and debugger/build artifacts;
- Visual Studio cache and generated project files;
- documents belonging to other students;
- copyrighted handouts and a document explicitly marked as not for redistribution;
- documents containing unnecessary student-number/class information;
- incomplete AppWizard/MFC boilerplate with no meaningful application logic.

CCF problem statements are not reproduced here. Only solution source code and short identifiers are included.
