# Programming fundamentals

These examples are **refactored versions** of representative exercises from the original course archive. They are not byte-for-byte historical submissions.

The cleanup focuses on:

- standard `int main(void)` entry points;
- bounds-safe input widths where applicable;
- correct pointer usage;
- valid array indexing;
- explicit function prototypes and return types;
- portable C11 syntax;
- descriptive English filenames.

The original archive also contained intentionally broken “find and fix the bug” exercises. Those broken versions are not published here; their concepts are represented by corrected implementations instead.
